Admin – Brukere

Opprett bruker

Administrator setter et midlertidig passord. Bruker må bytte ved første innlogging.

Nullstill passord

Brukernavn brukes som nøkkel. Backend finner riktig bruker og setter nytt midlertidig passord.

Endre rolle

Finn bruker via brukernavn, og aktiver eller fjern valgt rolle.
